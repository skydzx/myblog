## 一、草稿本上的密码

初三。午睡课。周围同学都趴下了，我睡不着，在草稿本上画了一个坐标系，横轴 5 格，纵轴 5 格，把 26 个英文字母随意填了进去。

没什么目的，纯粹觉得好玩。

那时候心里还有一个念头特别强烈——**想当一名黑客**。说不清是从哪部电影还是哪篇文章里看到的，就是觉得这两个字太酷了。能攻破别人的系统，能看见别人看不见的东西。但这个念头一直悬在空中，没有落地。

那张草稿纸后来丢了。但那个坐标系一直印在脑子里。

## 二、推开那扇门

大一，上了密码学专业课，我才知道——

**初三那个午睡课上的涂鸦，叫棋盘密码。**

公元前 2 世纪，希腊人波利比乌斯发明的。两千年后，一个江苏初中生在不知道它存在的情况下，重新把它"发明"了一次。

但棋盘密码，不过是密码学的冰山一角。

从凯撒密码到维吉尼亚密码，从 DES 到 AES，从对称加密到公钥基础设施，从椭圆曲线到格密码——大一那一整年，我像一块海绵，拼命吸水。密码学这扇门，终于推开了。

### 不止是密码学

大一不只有密码课。同时开设的**信息安全基础课**，让我第一次真正摸到了"攻击"的边。

老师上课不讲虚的，直接放案例：**ARP 欺骗**是怎么让局域网里的流量全部经过攻击者的机器；**APT 组织**是怎么在企业内网里潜伏好几年不被发现；一张看似普通的旅游照片，放大看路牌和地标，就能定位到经纬度——这是开源情报的基本功。

这些攻击手段不是课本上的概念。老师让我们自己在网上找工具，动手把案例复现一遍。ARP 欺骗就用 Cain & Abel 或者 Ettercap，信息收集就写爬虫，图片定位就去搜 EXIF 元数据。

那段时间，我同时还在自己折腾几件事：

**永恒之蓝漏洞复现。** 美国国家安全局泄露的 Windows 漏洞攻击工具，后来被 WannaCry 勒索病毒用到，席卷全球。我在虚拟机里搭了一台没打补丁的 Windows 7，用工具打过去——反弹 Shell 弹回来那一刻，手是抖的。不是害怕，是兴奋。一个端口没封好，一个补丁没打上，系统就没了。

**在 Kali 上搭建阿帕奇服务器。** 然后用 Metasploit 框架生成一个木马文件，放在服务器上。让物理机访问、下载、执行。执行成功的一瞬间，物理机上的杀毒软件弹窗了——红色警告，木马文件被识别、隔离、清除。那一刻我意识到两件事：免杀是一门真正的学问；杀软和攻击工具之间，就是一场永不停歇的猫鼠游戏。

也是从那时候起，我对安全有了一个最基本的信念：**不亲手搭过靶场、不亲自把漏洞打通过，就不叫学会。**

## 三、大师班

大一学期末，学校选拔大师班成员。

面试的时候，老师问了我几个方向的问题：密码学基础、信息安全、还有自己做过的实践。我把永恒之蓝漏洞复现的经历讲了一遍——怎么搭的环境、怎么打的、反弹 Shell 回来的那一瞬间什么感受。当时觉得老师的反馈还不错，心里有了底。

后来通知下来，选上了。

大师班里见到了真正的高手，也见识到了行业里真正在做安全的人是什么样子。这里不细说，但一句话总结：**它让我知道安全这条路能走多远。**

## 四、大二：在靶场里长肉

大二这一年，技能树开始分叉。

**Web 基础。** HTTP 协议、同源策略、Cookie 和 Session、SQL 注入、跨站脚本、跨站请求伪造、文件上传、命令注入——每一个漏洞原理都要追到协议层。

**Linux 基础。** 从 `ls` 开始，到用户权限、文件系统、进程管理、防火墙规则、系统服务。习惯了在纯黑终端里生活。

**网络技术基础。** 七层模型、三次握手四次挥手、子网划分、虚拟局域网、路由协议、Wireshark 抓包分析。学网络之前，觉得网络就是插上网线就能上网；学完之后才知道，每一层都是一整个宇宙。

**夺旗竞赛。** 开始打比赛。Web 题和杂项题是主力方向。逆向工程也上了课，但实操偏少——因为那个学期大部分时间在跟老师做项目。

> **项目：安全日志自动标注。**
>
> 核心工作：给海量安全日志打标签——按漏洞的危害程度分级、按来源地址出现的频次聚合、标记可疑行为。
>
> 这里有一个关键的事情：**这套标注系统本身就是用 AI 做的。** 我们用了通义千问和 DeepSeek 两个大语言模型对原始日志进行第一轮打标签。大模型先看一遍日志，给出它判断的标签——漏洞等级、攻击类型、威胁评分。然后我们做第二道工序：训练一个机器学习模型来核验大模型的标签。大模型说这个日志是"高危 SQL 注入"，小模型再来判断一次：同意还是不同意。
>
> 在这个项目里，我接触到了完整的机器学习流程。拿到数据先做预处理——空值怎么填、数据格式异常怎么检测、邮箱格式对不对、手机号位数够不够、身份证号校验位是否正确。数据洗干净之后，写算法做训练，涉及监督学习和无监督学习。为了处理海量日志，我们用 Spark 和 Hadoop 伪分布式跑训练，用 K 折交叉验证来评估模型效果。算法层面，接触到了 PCA 主成分分析做降维、OpenAI 客户端调用、提示词设计和入参调优。
>
> 这个项目让我第一次体会到：安全不只是攻防，数据、算法、工程能力缺一不可。

### 靶场实战

- **DVWA**：SQL 注入、跨站脚本、跨站请求伪造、文件上传、命令注入，十几个漏洞场景逐级打通。
- **Pikachu**：国内师傅写的靶场，配合 Burp Suite 抓包分析，搞清楚**为什么能打进去、怎么修、怎么防**。

比赛方面，杂项题做得最多：流量分析、内存取证、图片隐写、编码解码、压缩包破解。逆向虽摸了 IDA 和 Ghidra，实操偏少——以后要补的债。

### 内网渗透

从外围打点到获取第一个立足点，从本地提权到横向移动，从凭据窃取到域控拿下——每一步都是一张新地图。把视角从单台机器拉高到整个网络拓扑，这台和那台之间怎么通信、哪个服务暴露了、哪条路径可以走——看整个网络是一盘棋。

> 这里要特别感谢我的老师**杨雄老师**。他不光教我逆向工程，更重要的是带着我做项目，教会了我很多现实中的事、社会上的道理。大学能遇到这样的老师，是我的运气。

## 五、AI 这条路

大三，AI 全面进入了我的工具箱。

### 大模型辅助

其实在 DeepSeek 爆火之前，我就已经在用百度的文心一言了。环境配置报错了，贴进去让它看；代码跑不通，贴进去让它查；概念不懂，让它解释。后来 DeepSeek 出来后也一直在用。大模型帮我解决了一堆环境搭建、代码调试、概念理解的问题——不是替代思考，而是把查资料的时间缩短了十倍。

### 本地部署

有段时间，我想试试把大模型跑到自己机器上。在自己的 3050 笔记本上部署了 DeepSeek-R1 7B——能跑，但慢。每秒几个字的输出速度，想用它干活不现实，但跑通那一刻的意义大于实用。

后来在公司接触到 AI 算力服务器，上面跑着 Qwen 3.6B 到 35B 不同规格的模型。这才知道什么是推理速度、什么是显存瓶颈、7B 和 35B 的差距到底有多大。

### 工具链

这些工具我都摸过：

- **Ollama**：一键启动本地大模型，DeepSeek、Qwen、Llama 都能跑
- **LM Studio**：带图形界面的本地模型管理工具，适合不想碰命令行的场景
- **llama.cpp**：纯 C++ 的模型推理引擎，能在 CPU 上跑，吃资源极小
- **Chatbox / Cherry Studio**：连接本地 Ollama 或在线 API 的桌面客户端，日常使用最方便

这些工具各有各的用。Ollama 管模型上下架，LM Studio 看显存占用，llama.cpp 极限压榨性能，Chatbox 负责日常对话。

### AI 不只是大模型

从那个日志标注项目开始，我对 AI 的理解就不限于对话机器人了。AI 是一整个技术栈：

- **智能体 (Agent)**：让大模型不只是回答问题，而是能调用工具、执行任务、自主规划步骤
- **检索增强生成 (RAG)**：先搜索再回答，把知识库和模型结合起来
- **技能 (Skill)**：给模型定义固定流程的能力单元，比如我那两个 Claude Code 技能
- **机器学习**：数据预处理、特征工程、监督学习、无监督学习、模型评估、K 折交叉验证
- **大数据**：Spark、Hadoop HDFS、分布式计算——日志量大了，单机跑不动

从"用 AI 给日志打标签"到"训练小模型核验大模型"，再到"本地部署、工具链搭建、理解整个 AI 技术栈"——这条线跟安全本来没关系，但现在越来越分不开了。

## 六、领航杯

后来参加了**领航杯**网络安全竞赛。赛制是 RDG（Real Data Game），团队赛，一场打下来大概三四个小时。具体比了多久记不太清了，只记得全程高度紧张，一秒都没松懈过。

结果是——**特等奖**。

那个奖杯搬回来的时候，我在想初三那个午睡课的下午。如果有谁告诉当时的我："你以后会拿一个网络安全比赛的奖"，我肯定不信。

大三。在常州找到了一份不错的安全工作。每天跟漏洞、流量、日志、渗透测试打交道。

「棋密」这个博客，是我的数字花园——不定时记录安全研究、密码学笔记、AI 工具心得、算法笔记，和路上的碎碎念。

从一张草稿纸走到这里，用了七年。

路还长。
