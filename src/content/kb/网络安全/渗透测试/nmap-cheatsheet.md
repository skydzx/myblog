## 基础用法

```bash
# 快速扫描常用端口
nmap -F 192.168.1.1

# 全端口扫描
nmap -p- 192.168.1.1

# 服务版本探测
nmap -sV 192.168.1.1

# OS 探测
nmap -O 192.168.1.1
```

## 综合扫描（最常用）

```bash
nmap -sV -sC -p- -T4 -oA scan_result 192.168.1.1
```

| 参数 | 含义 |
|------|------|
| `-sV` | 服务版本探测 |
| `-sC` | 默认脚本扫描 |
| `-p-` | 1-65535 全端口 |
| `-T4` | 速率模板（0-5，4 推荐） |
| `-oA` | 输出全部格式 |

## 防火墙规避

```bash
# 分片扫描
nmap -f 192.168.1.1

# 诱饵扫描
nmap -D RND:5 192.168.1.1

# 空闲扫描（隐蔽）
nmap -sI zombie_host 192.168.1.1
```
