> 个人 CTF 隐写作业合集整理。工具：010 Editor、binwalk、stegsolve、ziperello、Python。

## 1. PNG 文件头修复

```text
现象：010 中看到 IHDR/IEND 可判断是 png，但文件头不完整
png 文件头：89 50 4E 47 0D 0A 1A 0A（8字节）
缺失时：edit → insert → 补上缺失字节，保存后改后缀 .png
```

## 2. binwalk 分离隐藏文件

```bash
# 图片尾部藏着 zip / 其他文件时
binwalk -Me --run-as=root veryeasy.png
# 分离出 zip / 隐藏文件
```

## 3. LSB 隐写（stegsolve）

```text
1. stegsolve 打开图片 → Analyse → Data Extract
2. 选择 Red/Green/Blue 的 Bit 0（最低位）——信息常隐写在最低位不易察觉
   （Alpha 透明度一般不考；最高位/中间字段从图上容易看出，不藏信息）
3. Preview 看到 zip 头（50 4B 03 04）→ Save Bin 保存
4. 010 打开，去掉多余数据（zip 以 05 06 结尾），存成 .zip
5. zip 要密码 → ziperello/ARCHPR 爆破
```

## 4. 综合案例：网鼎杯 图片隐写

```text
1. 010 查看 → png 尾部有 zip 头 → binwalk 分离
2. 分离出 zip：看到 CRC32 + 文件仅 6 字节 → 尝试 CRC32 碰撞
   python3 crc32.py reverse <CRC32值>
3. zip 密码在这些字母中 → 生成字典 → ziperello 字典爆破 → 得到密码
4. 加密文件用 veracrypt 打开 → 找到私钥 → 手搓私钥
5. 010 中直接搜 "flag" → 找到但不完整（flag.txt）→ 补全再 binwalk 分离
6. 得到 base64 密文 → RSA 在线工具解密 → flag
```

> 关键点：**CRC32 碰撞**（小文件可直接还原内容）、**010 搜关键字**找遗漏、**RSA 私钥 + 密文 → 解密**。

## 5. 工具速查

```text
010 Editor    看文件头/十六进制/搜关键字/插字节
binwalk       检测并分离隐藏文件
stegsolve     LSB/MSB 隐写提取
ziperello     zip 密码字典/掩码爆破
ARCHPR        zip 暴力破解
veracrypt     加密容器挂载
Python        CRC32 碰撞脚本、字典生成
```

---

> **一句话总结**：图片隐写 = 看文件头（修复/识别）→ binwalk 分离 → LSB 提取 → 处理加密（CRC32/字典爆破/veracrypt）→ 还原 flag。**010 搜关键字**往往能直接找到被隐藏的 flag。
