## 1. 空口令检查（零容忍）

```bash
# 检查 shadow 中密码字段为空的账号
awk -F: '($2 == "") {print "🚨 空口令: "$1}' /etc/shadow

# 检查被锁定但仍可本地登录的账号
awk -F: '($2 == "!" || $2 == "!!") {print "🔒 锁定: "$1}' /etc/shadow

# 综合检查：排除 nologin/false，只看真正可登录的空口令账号
awk -F: '$2=="" {print $1}' /etc/shadow | while read u; do
    sh=$(getent passwd "$u" | cut -d: -f7)
    [[ "$sh" != */nologin && "$sh" != */false ]] && \
    echo "🚨 高危可登录空口令账号: $u → $sh"
done
```

修复：

```bash
passwd -l <username>      # 锁定
passwd -d <username>      # 删除密码（不推荐）
usermod -s /sbin/nologin <username>  # 禁止登录
```

## 2. UID / GID 异常检查

```bash
# UID=0 的非 root 账号（后门常见）
awk -F: '$3==0 && $1!="root" {print "🚨 UID=0异常: "$1}' /etc/passwd

# GID=0 的非 root 组
awk -F: '$3==0 && $1!="root" {print "🚨 GID=0异常组: "$1}' /etc/group

# UID 重复
awk -F: '{print $3}' /etc/passwd | sort | uniq -d | while read uid; do
    echo "⚠️ 重复UID $uid:"
    awk -F: -v u="$uid" '$3==u {print "  "$1}' /etc/passwd
done

# 用户名重复（理论上不应出现）
awk -F: '{print $1}' /etc/passwd | sort | uniq -d
```

## 3. 系统账号与僵尸账号

```bash
# 可登录的系统账号（UID<1000，排除 root）
awk -F: '$3<1000 && $3!=0 && $7!~/nologin|false/ {print "⚠️ "$1" UID="$3" Shell="$7}' /etc/passwd

# 从未登录 / 超过90天未登录
lastlog | grep "Never logged in"
lastlog -b 90 | grep -v "Never" | grep -v "Username"

# 修复：禁用不需要的账号
usermod -L -s /sbin/nologin <username>

# 检查 /etc/passwd 与 /etc/shadow 一致性
pwck -r    # 只读模式检查
grpck -r   # 检查组文件一致性
```

## 4. sudo 权限管控

```bash
# 检查 sudoers 配置
cat /etc/sudoers
ls -la /etc/sudoers.d/ && cat /etc/sudoers.d/*

# 检查 NOPASSWD（免密 sudo）与 ALL（权限过宽）
grep -rn "NOPASSWD" /etc/sudoers /etc/sudoers.d/
grep -rn "ALL" /etc/sudoers /etc/sudoers.d/

# 检查 sudo 日志
grep -i sudo /var/log/secure /var/log/auth.log 2>/dev/null | tail -50
```

加固：

```bash
# sudo 日志记录
echo 'Defaults log_host, log_year, logfile="/var/log/sudo.log"' >> /etc/sudoers
# 限制 sudo 超时（默认5分钟）
echo 'Defaults timestamp_timeout=3' >> /etc/sudoers
```

## 5. su 提权限制

```bash
# 检查 su 是否被限制
grep "pam_wheel" /etc/pam.d/su

# 加固：仅 wheel 组成员可 su
# /etc/pam.d/su 中取消注释:
auth    required    pam_wheel.so use_uid

# 确认 wheel 组成员
getent group wheel
```

## 6. 信任关系文件与 SSH 密钥检查

```bash
# 检查 .rhosts / .netrc / hosts.equiv（旧信任机制，应不存在）
find / -name ".rhosts" -o -name ".netrc" -o -name "hosts.equiv" 2>/dev/null

# 排查 authorized_keys 中的未知公钥
find /home /root -name "authorized_keys" -exec sh -c \
  'echo "=== {} ==="; cat {}; ls -la {}' \;
```

## 7. 密码复杂度策略

RHEL/CentOS（`/etc/security/pwquality.conf`）：

```ini
minlen = 12            # 最小长度12
dcredit = -1           # 至少1个数字
ucredit = -1           # 至少1个大写
lcredit = -1           # 至少1个小写
ocredit = -1           # 至少1个特殊字符
reject_username        # 禁止包含用户名
enforce_for_root       # root 也强制
maxrepeat = 3          # 同字符最多连续3次
maxclassrepeat = 4     # 同类型字符最多连续4个
```

Ubuntu/Debian（`/etc/pam.d/common-password`）：

```bash
grep pwquality /etc/pam.d/common-password
# 若未安装: apt install libpam-pwquality
```

## 8. 密码有效期策略

```bash
# 全局策略
grep -E "^PASS_(MAX|MIN|WARN)_DAYS|^PASS_MIN_LEN" /etc/login.defs
```

加固值：

```text
PASS_MAX_DAYS   90    最长90天
PASS_MIN_DAYS   7     最短7天（防立即改回）
PASS_WARN_AGE   14    提前14天告警
PASS_MIN_LEN    12    最小长度
```

批量修复 + 强制改密：

```bash
awk -F: '$3>=1000{print $1}' /etc/passwd | xargs -I{} chage -M 90 -m 7 -W 14 {}
chage -d 0 <username>   # 强制下次登录改密
```

## 10. 登录失败锁定（防暴力破解）

```bash
# RHEL 7+ 使用 pam_faillock
# 加固配置:
# auth required pam_faillock.so preauth silent audit deny=5 unlock_time=600 even_deny_root
# auth required pam_faillock.so authfail audit deny=5 unlock_time=600
# account required pam_faillock.so

# 查看 / 重置锁定
faillock --user <username>             # RHEL7+
faillock --user <username> --reset

# RHEL 6 使用 pam_tally2
pam_tally2 --user <username> --reset
```

## 11. 密码哈希算法检查

```bash
# $6$=SHA-512, $1$=MD5(弱), $2$=Blowfish
awk -F: '$2!~/^\$6\$/ && $2!~/^[!*]/ {print "⚠️ 非SHA-512: "$1" → "substr($2,1,3)}' /etc/shadow

grep ENCRYPT_METHOD /etc/login.defs     # 期望 SHA512
grep crypt_style /etc/libuser.conf      # 期望 sha512
```

## 12. 弱口令检测

```bash
# 方案一：John the Ripper（推荐）
yum install -y john epel-release   # RHEL
apt install -y john                # Debian/Ubuntu

unshadow /etc/passwd /etc/shadow > /tmp/.hash_tmp
john --wordlist=/usr/share/john/password.lst /tmp/.hash_tmp
john --show /tmp/.hash_tmp
shred -u /tmp/.hash_tmp            # 用完立即销毁

# 方案二：nmap NSE 脚本（远程，需授权）
nmap --script ssh-brute -p 22 --script-args userdb=users.txt,passdb=weak.txt <target_ip>
```

> ⚠️ 弱口令扫描会触发大量失败登录记录，建议在维护窗口进行，并先确认无入侵检测告警联动。
