> 个人 Windows 安全实验报告整理。

## 一、实验目的

验证如何在 Windows 中设置登录密码的有效期，降低密码长期不更换的安全风险。

## 二、实验原理

Windows 提供设置密码有效期的功能，可通过**系统策略**或**命令**设置密码过期时间。密码到期后系统提示用户更改，确保时效性。

## 三、实验环境

```text
操作系统：Windows 11
硬件：i5 / 16GB / 512GB SSD
```

## 四、实验步骤

```text
1. 打开策略编辑器：
   - Windows 11 家庭版无组策略编辑器 → 用 lusrmgr.msc 打开用户组管理
2. 导航到密码策略：
   计算机配置 → Windows 设置 → 安全设置 → 账户策略 → 密码策略
3. 修改"密码最长使用期限"（例如 90 天）
   - 可同时修改"密码必须符合复杂性要求"等
4. 应用并保存
5. 验证：
   - 超过有效期后登录，观察是否提示更改密码
   - 或用 net user 命令查看密码过期状态
```

## 五、命令方式（补充）

```cmd
net user <username> /expires:<date>          :: 设置账户过期
# 查看密码过期状态
net user <username>
```

## 六、结论

成功设置密码有效期，到期提示改密。建议定期改密 + 启用有效期，增强系统安全。
