## 1. firewalld（RHEL 7+/CentOS 7+）

```bash
systemctl status firewalld
firewall-cmd --state
firewall-cmd --list-all

# 默认区域设为 drop（拒绝一切，仅放行白名单）
firewall-cmd --set-default-zone=drop

# 仅开放必要端口
firewall-cmd --permanent --zone=drop --add-port=2222/tcp    # SSH
firewall-cmd --permanent --zone=drop --add-port=80/tcp      # HTTP
firewall-cmd --permanent --zone=drop --add-port=443/tcp     # HTTPS

# 限制 SSH 来源 IP
firewall-cmd --permanent --zone=drop \
  --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" port port="2222" protocol="tcp" accept'

firewall-cmd --reload
firewall-cmd --list-all
```

> ⚠️ 切到 `drop` 区域前，务必先放行自己的管理端口/来源，否则会被锁在门外。

## 2. iptables（通用）

```bash
iptables -L -n -v --line-numbers

# 默认策略 DROP（先确保放行管理连接！）
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT   # 出站通常放行

# 允许已建立连接 + loopback
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
iptables -A INPUT -i lo -j ACCEPT

# 放行 SSH（指定来源）+ HTTP/HTTPS
iptables -A INPUT -p tcp --dport 2222 -s 192.168.1.0/24 -j ACCEPT
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# ICMP 限速
iptables -A INPUT -p icmp --icmp-type echo-request -m limit --limit 1/s -j ACCEPT

# 记录并拒绝其余
iptables -A INPUT -m limit --limit 5/min -j LOG --log-prefix "IPTABLES-DROP: "
iptables -A INPUT -j DROP

# 保存
iptables-save > /etc/sysconfig/iptables   # RHEL
netfilter-persistent save                 # Debian/Ubuntu

# 防止 IPv6 绕过
ip6tables -P INPUT DROP
ip6tables -A INPUT -i lo -j ACCEPT
ip6tables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
```

## 3. nftables（新一代）

```bash
cat > /etc/nftables.conf << 'EOF'
#!/usr/sbin/nft -f
flush ruleset

table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;
        ct state established,related accept
        iif "lo" accept
        tcp dport 2222 ip saddr 192.168.1.0/24 accept
        tcp dport {80, 443} accept
        icmp type echo-request limit rate 1/second accept
        log prefix "NFT-DROP: " counter
    }
    chain forward {
        type filter hook forward priority 0; policy drop;
    }
    chain output {
        type filter hook output priority 0; policy accept;
    }
}
EOF

nft -f /etc/nftables.conf
systemctl enable --now nftables
```

## 4. 规则审计

```bash
# 全放通规则应避免
iptables -L -n | grep "0.0.0.0/0" | grep ACCEPT

# 计数器为 0 的规则可能已无用
iptables -L -n -v | awk '$1==0 && $2==0 {print NR": "$0}'

# 从外部验证端口可达性
nmap -sT -p <port> <target_ip>
nc -zv <target_ip> <port>
```

## 5. 加固思路小结

1. **默认拒绝（DROP），白名单放行**——比默认 ACCEPT + 黑名单安全得多
2. **管理端口限制来源 IP**——SSH/数据库只对管理网段开放
3. **IPv6 单独处理**——很多环境只配了 iptables 忘了 ip6tables，导致 IPv6 通道绕过
4. **规则保存与基线 diff**——改完保存，定期对比是否有意外新增规则
