> 对应「Linux 安全基线加固手册」第 18 章。缓存/消息队列**默认无认证 + 弱默认配置**，是内网横向移动的重灾区。

## 1. Redis

```bash
REDIS_CONF="/etc/redis.conf"    # 或 /etc/redis/redis.conf

# 1. 绑定地址（❌ 禁止 0.0.0.0）
grep "^bind" $REDIS_CONF
# 加固: bind 127.0.0.1 或指定内网 IP

# 2. 密码认证（≥32位）
grep "^requirepass" $REDIS_CONF
# 生成: openssl rand -base64 32

# 3. 禁用危险命令（防删库/配置篡改）
cat >> $REDIS_CONF << 'EOF'
rename-command FLUSHALL ""
rename-command FLUSHDB ""
rename-command CONFIG ""
rename-command KEYS ""
rename-command SHUTDOWN ""
rename-command DEBUG ""
rename-command EVAL ""
EOF

# 4. 保护模式 + 非 root 运行
grep "^protected-mode" $REDIS_CONF    # 期望 yes
ps aux | grep redis                   # 期望 redis 用户

# 5. 文件权限
chmod 640 $REDIS_CONF && chown redis:redis $REDIS_CONF
chmod 750 /var/lib/redis && chown redis:redis /var/lib/redis

systemctl restart redis
```

> Redis 默认配置绑定 `0.0.0.0` 且无密码，**公网 Redis 被入侵 → 提权/写入 SSH 公钥**是经典攻击链。必须绑定内网 + 强密码 + 禁用危险命令。

## 2. RabbitMQ

```bash
# 修改默认 guest 账号（弱口令+全权限）
rabbitmqctl delete_user guest
rabbitmqctl add_user admin_$(openssl rand -hex 4) "$(openssl rand -base64 24)"
rabbitmqctl set_user_tags <new_admin> administrator
rabbitmqctl set_permissions -p / <new_admin> ".*" ".*" ".*"

# 管理界面默认 15672，考虑限制 IP
# Erlang Cookie 权限
chmod 400 /var/lib/rabbitmq/.erlang.cookie && chown rabbitmq:rabbitmq /var/lib/rabbitmq/.erlang.cookie

# 检查用户/权限
rabbitmqctl list_users && rabbitmqctl list_permissions
```

## 3. Kafka + Zookeeper

```bash
KAFKA_HOME="/opt/kafka"
KAFKA_CONF="$KAFKA_HOME/config/server.properties"

# 监听地址（不应 0.0.0.0）
grep "listeners\|advertised.listeners" $KAFKA_CONF

# 认证（SASL_SCRAM）与 ACL
# security.inter.broker.protocol=SASL_SSL
# sasl.enabled.mechanisms=SCRAM-SHA-256

# ZK 禁用四字命令 / 限制监听
# zoo.cfg: 4lw.commands.whitelist=stat,ruok
#          clientPortAddress=127.0.0.1

# 运行用户
ps aux | grep -E "kafka|zookeeper" | grep -v grep   # 非 root
```

## 4. Elasticsearch

```bash
ES_CONF="/etc/elasticsearch/elasticsearch.yml"

# 绑定地址（❌ 禁止 0.0.0.0）
grep "network.host\|http.port" $ES_CONF
# 加固: network.host: 127.0.0.1 或内网 IP

# 开启 X-Pack 认证
# xpack.security.enabled: true
/usr/share/elasticsearch/bin/elasticsearch-setup-passwords interactive

# 禁用动态脚本
# script.inline: false / script.stored: false

# 运行用户
ps aux | grep elasticsearch    # 期望 elasticsearch 用户
```

> ES 默认 `network.host: 0.0.0.0` 且无认证，公网暴露 = 数据裸奔，常被勒索/挖矿利用。

## 5. Memcached

```bash
MEMCACHED_CONF="/etc/sysconfig/memcached"    # RHEL
# 或 /etc/memcached.conf                      # Debian

# 绑定地址 + 禁用 UDP（防放大攻击）+ 非 root
grep -E "^\-l" $MEMCACHED_CONF     # 加固: -l 127.0.0.1
grep -E "^\-U" $MEMCACHED_CONF     # 加固: -U 0
grep -E "^\-u" $MEMCACHED_CONF     # 期望: -u memcache
```

## 6. 通用检查

```bash
# 端口暴露（Redis 6379 / Rabbit 5672 / Kafka 9092 / ES 9200 / Memcached 11211）
ss -tulnp | grep -E "6379|5672|9092|9200|11211|2181"

# 无认证访问测试（验证是否默认可连）
redis-cli -h <ip> ping 2>&1 | grep -i "auth\|denied"
# 若返回 PONG 且无 auth 要求 → 严重风险
```
