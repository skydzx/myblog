> 对应「Linux 安全基线加固手册」第 19 章。核心思路：**默认不绑公网、强密码、最小权限、开审计**。

## 1. MySQL / MariaDB

```bash
# 首次安装后安全初始化
mysql_secure_installation

# 检查用户：匿名用户 / 空密码 / 远程 root / 超级权限
mysql -u root -p -e "
SELECT user, host FROM mysql.user WHERE user='';              -- 空用户名
SELECT user, host FROM mysql.user WHERE host='%';              -- 远程访问
SELECT user, host FROM mysql.user WHERE authentication_string=''; -- 空密码
SELECT user, host FROM mysql.user WHERE Super_priv='Y' AND user != 'root';
"

# 修复
mysql -u root -p -e "DROP USER ''@'localhost'; DROP USER ''@'%';"
mysql -u root -p -e "UPDATE mysql.user SET host='localhost' WHERE user='root'; FLUSH PRIVILEGES;"
```

绑定与危险功能：

```bash
# 绑定地址（仅本地或内网）
grep "bind-address" /etc/my.cnf /etc/mysql/mysql.conf.d/mysqld.cnf 2>/dev/null
# 加固: bind-address = 127.0.0.1

# 禁用 LOAD DATA LOCAL INFILE（防客户端文件读取）
cat >> /etc/my.cnf << 'EOF'
[mysqld]
local_infile = 0
symbolic-links = 0
max_connections = 200
wait_timeout = 300
EOF

# 日志
cat >> /etc/my.cnf << 'EOF'
[mysqld]
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2
log_error = /var/log/mysql/error.log
EOF

# 文件权限 + 删 test 库
chmod 750 /var/lib/mysql && chown mysql:mysql /var/lib/mysql
mysql -u root -p -e "DROP DATABASE IF EXISTS test;"
```

## 2. PostgreSQL

```bash
PG_CONF_DIR="/var/lib/pgsql/data"     # RHEL，Ubuntu 在 /etc/postgresql/<version>/main

# 监听地址
grep "listen_addresses" $PG_CONF_DIR/postgresql.conf
# 加固: listen_addresses = 'localhost' 或内网 IP

# pg_hba.conf 访问控制（禁用 0.0.0.0/0 trust）
cat > $PG_CONF_DIR/pg_hba.conf << 'EOF'
# TYPE  DATABASE  USER      ADDRESS         METHOD
local   all       postgres                  peer
local   all       all                       scram-sha-256
host    all       all       127.0.0.1/32    scram-sha-256
host    all       all       192.168.1.0/24  scram-sha-256
EOF

# 检查空密码 / 超级用户 / 权限过大角色
sudo -u postgres psql -c "SELECT usename FROM pg_shadow WHERE passwd IS NULL;"
sudo -u postgres psql -c "SELECT rolname, rolsuper FROM pg_roles WHERE rolcanlogin = true;"

# 日志 + 限制
# log_connections = on / log_disconnections = on / log_statement = 'ddl'
# idle_in_transaction_session_timeout = 60000

chmod 700 $PG_CONF_DIR && chown -R postgres:postgres $PG_CONF_DIR
```

## 3. MongoDB

```bash
MONGO_CONF="/etc/mongod.conf"

# 绑定地址（禁止 0.0.0.0）
# net: bindIp: 127.0.0.1

# 启用认证
# security: authorization: enabled
mongosh --eval 'use admin
db.createUser({
  user: "admin_'$(openssl rand -hex 4)'",
  pwd: "'$(openssl rand -base64 24)'",
  roles: [{role: "userAdminAnyDatabase", db: "admin"}]
})'

# 禁用服务端脚本
# security: javascriptEnabled: false

# 运行用户 / 日志
ps aux | grep mongod          # mongod 用户
grep -A3 "systemLog:" $MONGO_CONF   # destination: file
```

## 4. 通用数据库检查清单

```bash
# 端口暴露
ss -tulnp | grep -E "3306|5432|1521|1433|27017"

# 进程运行用户（不应是 root）
ps aux | grep -E "mysql|postgres|oracle|mssql|mongo"

# 数据目录 / 配置文件权限
ls -la /var/lib/mysql /var/lib/postgresql /var/lib/mongo 2>/dev/null
ls -la /etc/my.cnf /etc/mongod.conf 2>/dev/null

# 无认证连通性测试
mysql -u root -h 127.0.0.1 -e "SELECT 1" 2>&1 | grep -i "denied\|password"
redis-cli -h 127.0.0.1 ping 2>&1 | grep -i "auth\|denied"

# 备份文件泄露排查
find / -name "*.sql" -o -name "*.bak" -o -name "*.dump" -o -name "*.rdb" 2>/dev/null | grep -v proc
```

## 5. 加固要点小结

1. **绝不绑 `0.0.0.0`**——数据库只该对应用服务器网段开放
2. **删除默认/匿名账号**——root 只留 localhost
3. **最小权限**——应用账号只给业务库的最小权限，不用 root 连接
4. **开审计日志**——连接/慢查询/错误日志，便于溯源
5. **定期备份并加密**——备份文件本身是敏感数据
