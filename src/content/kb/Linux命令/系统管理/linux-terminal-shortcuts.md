## Bash 行编辑（光标移动）

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+A` | 光标跳到行首 |
| `Ctrl+E` | 光标跳到行尾 |
| `Ctrl+B` / `→` | 光标左移一格 |
| `Ctrl+F` / `←` | 光标右移一格 |
| `Alt+B` | 左移一个单词 |
| `Alt+F` | 右移一个单词 |
| `Ctrl+XX` | 在当前位置和行首之间来回跳 |

---

## 文本删除与剪切

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+D` | 删除光标处字符（行尾时等于退出终端） |
| `Ctrl+H` | 退格（删除光标前字符） |
| `Ctrl+K` | 剪切光标到行尾 |
| `Ctrl+U` | 剪切光标到行首 |
| `Ctrl+W` | 剪切光标前一个单词 |
| `Alt+D` | 剪切光标后一个单词 |
| `Ctrl+Y` | 粘贴最近剪切的文本 |
| `Alt+Y` | 循环粘贴之前的剪切内容 |

> 命令输错了想整行重来 → `Ctrl+U` 或 `Ctrl+C`

## 终端控制

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+C` | 终止当前命令（SIGINT） |
| `Ctrl+Z` | 挂起当前命令到后台（配合 `fg` 恢复） |
| `Ctrl+D` | 退出终端（EOF） |
| `Ctrl+L` | 清屏（相当于 `clear`，但保留历史） |
| `Ctrl+S` | 冻结终端输出 |
| `Ctrl+Q` | 解冻终端输出 |
| `Ctrl+R` | 反向搜索历史命令（再按 `Ctrl+R` 继续往上） |
| `Ctrl+G` | 退出搜索模式 |
| `Ctrl+T` | 交换光标前后两个字符 |
| `Shift+PageUp/PageDown` | 终端里翻页 |

> `Ctrl+Z` 挂起后：`fg` 回到前台，`bg` 在后台继续跑，`jobs` 查看所有挂起任务

## 历史记录

```bash
history               # 查看历史
history | grep xxx    # 搜索历史
!n                    # 执行第 n 条历史命令
!!                    # 执行上一条命令
!$                    # 上一条命令的最后一个参数
!*                    # 上一条命令的所有参数
!ls                   # 执行最近一条以 ls 开头的命令
```

## Tab 补全

| 操作 | 作用 |
|------|------|
| `Tab` | 补全命令 / 路径 / 文件名 |
| `Tab` `Tab`（连按两次） | 列出所有可能的补全项 |
| `Alt+.` | 粘贴上一条命令的最后一个参数 |
| `Alt+数字` | 快速输入字符（如 `Alt+3` 然后按 `x` 输入 `xxx`） |

## 作业管理（前台/后台）

```bash
command &             # 后台运行
nohup command &       # 后台运行，退出终端不中断
Ctrl+Z                # 挂起
jobs                  # 查看作业列表
fg %1                 # 把作业 1 调到前台
bg %1                 # 把作业 1 放到后台运行
kill %1               # 终止作业 1
```

## 组合命令与管道

```bash
cmd1 && cmd2          # cmd1 成功才执行 cmd2
cmd1 || cmd2          # cmd1 失败才执行 cmd2
cmd1 | cmd2           # 管道，cmd1 输出作为 cmd2 输入
cmd1 ; cmd2           # 顺序执行，无论成败
( cmd1; cmd2 )        # 子 shell 中执行（不污染当前环境）
cmd1 $(cmd2)          # 命令替换
```

## 常见坑

- `Ctrl+D` 在空行按 = 退出登录，在命令中间按 = 删除字符，别搞混
- `Ctrl+S` 冻结输出后，很多人以为卡死了 → 按 `Ctrl+Q` 解冻
- `Ctrl+Z` 是挂起不是终止，进程还在内存里占着资源，不用就 `kill %1`
- 长时间运行任务用 `nohup` 或 `tmux`/`screen`，否则 SSH 断开任务就没了
