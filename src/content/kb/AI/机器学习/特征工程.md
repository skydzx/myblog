> 个人机器学习笔记整理。特征工程 = 特征选择 + 特征转换 + 特征缩放，显著提升模型性能、降低复杂度、增强可解释性。

## 1. 特征选择

目的：从原始特征中选最有预测价值的，提升性能、降低过拟合。

### 过滤方法（Filter）

用统计测试评估特征与目标关系，选得分最高/最低。

```text
相关系数法：Pearson（线性）、Spearman（等级）、Kendall（重复值多）
互信息法：衡量特征与目标的互信息量
方差阈值法：删除低方差特征（方差小 → 信息少）
```

优点：简单、计算快；缺点：不考虑特征交互。

### 包装方法（Wrapper）

以模型性能（准确率/AUC）为依据选择特征。

```text
递归特征消除（RFE）：全特征训练 → 移除最差 → 再训练，递归到目标数
```

### 嵌入方法（Embedded）

模型训练中自动选择特征。

```text
Lasso 回归：L1 正则使部分特征系数变 0，实现稀疏选择
```

## 2. 特征转换

### 对数转换（处理长尾分布）

```python
data['log_feature'] = np.log(1 + data['feature'])
```

### 幂次转换

```python
data['power_feature'] = data['feature'] ** 0.2
```

### 分位数转换（转为均匀/正态分布）

```python
from sklearn.preprocessing import QuantileTransformer
qt = QuantileTransformer(n_quantiles=10, random_state=42)
data['quantile_feature'] = qt.fit_transform(data[['feature']])
```

### 独热编码（类别 → 多个二元特征）

```python
data = pd.get_dummies(data, columns=['category_feature'])
```

### 均值编码（目标编码，高基数离散特征）

```python
mean_encoding = data.groupby('category_feature')['target'].mean()
data['mean_encoding_feature'] = data['category_feature'].map(mean_encoding)
```

## 3. 特征缩放

对距离度量算法（KNN/SVM）和神经网络至关重要——尺度不一致会让模型过度关注大尺度特征，或导致梯度消失/爆炸。

### 最小最大缩放（[0,1]）

```python
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
data['scaled_feature'] = scaler.fit_transform(data[['feature']])
```

### 标准化（均值0、标准差1）

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
data['standardized_feature'] = scaler.fit_transform(data[['feature']])
```

### 鲁棒缩放（对异常值不敏感，基于中位数/IQR）

```python
from sklearn.preprocessing import RobustScaler
scaler = RobustScaler()
data['robust_scaled_feature'] = scaler.fit_transform(data[['feature']])
```

> ⚠️ 在**训练集**上 `fit_transform`，测试集只用 `transform`（用训练集统计量），防止信息泄露。

---

> **一句话总结**：特征工程先把"该留的留下"（选择），再"变换出更有意义的"（转换），最后"统一尺度"（缩放）。选对方法比盲目堆特征更能提升模型。
