
## 2. 线性模型

### 逻辑回归（Logistic Regression）

```text
二分类线性模型，Sigmoid 映射到 0-1 概率
P(y=1|x) = 1 / (1 + e^(-z))，z = w₀ + w₁x₁ + ...
```

优点：训练快、可解释性强（权重直观）、输出概率、正则化防过拟合。
缺点：只能线性边界、依赖特征工程、对异常值敏感。

WebShell 检测：马泽辉（2019）用 5 个核心特征（信息熵、重合指数、最长单词、压缩比、危险函数匹配）准确率 93.1%。

```python
LogisticRegression(max_iter=2000, C=1.0, solver='lbfgs', random_state=42)
```

### 线性回归

预测连续值，最小化平方误差。主要用于评分/排序，较少用于二分类。

## 3. 树模型

### 决策树（Decision Tree）

基于规则的分层决策，每次选最优特征分割。

优点：可解释强、无需特征缩放、支持非线性、天然多分类。
缺点：易过拟合、不稳定（数据微小变化树完全不同）、连续特征需离散化。

WebShell 检测：杨秀璋论文对比实验准确率 95.90%。

### 随机森林（Random Forest）

集成学习：多棵决策树投票，Bagging 减少方差。

优点：抗过拟合、可分析特征重要性、处理高维、对缺失值鲁棒。
缺点：训练时间长、模型文件大、内存占用高。

WebShell 检测：准确率 94.92%，训练 15.4 分钟，推理 6866 样本/秒。

```python
RandomForestClassifier(n_estimators=100, max_depth=20, min_samples_split=5, random_state=42, n_jobs=-1)
```

### GBDT（梯度提升决策树）

串行集成：每棵树纠正前一棵树的错误（残差学习）。

优点：准确率高、特征重要性分析、强非线性。
缺点：易过拟合、训练慢（串行）、对异常值敏感。

### LightGBM（轻量级梯度提升机）

GBDT 优化版，基于直方图 + Leaf-wise 增长。

优点：训练快（比 GBDT 快 10 倍+）、内存小、准确率高、支持 GPU。
缺点：小数据集易过拟合。

WebShell 检测（本项目）：准确率 97.27%、召回率 96.50%，训练 27.2 分钟，推理 8396 样本/秒——最优。

## 4. 概率模型

### 朴素贝叶斯（Naive Bayes）

基于贝叶斯定理，假设特征独立。

```text
P(y|x₁,...,xₙ) ∝ P(y) × ∏P(xᵢ|y)
```

优点：训练快、适合小样本、对噪声不敏感、多分类友好。
缺点：独立性假设过强、需离散特征、对未见组合无法预测。

WebShell 检测：准确率 89.98%（较差），更适合文本分类。

## 5. 基于实例

### K近邻（KNN）

K 个最近邻居投票分类，"懒学习"无需训练。

优点：简单直观、无需训练、对异常值不敏感、适合非线性。
缺点：预测计算开销大、维度灾难、K 值难选、对不平衡数据敏感。

## 6. 支持向量机（SVM）

最大化分类间隔，核函数处理非线性。

优点：泛化强、适合高维、内存效率高（只存支持向量）、理论完备。
缺点：大数据集训练慢（O(n²)/O(n³)）、对参数敏感、可解释差、对缺失值敏感。

核函数：线性核（线性可分）、RBF 核（非线性，最常用）、多项式核。

WebShell 检测：准确率 96.00%。大数据集用 `LinearSVC`（快）。

```python
LinearSVC(random_state=42, max_iter=2000, dual=False, C=1.0)
```

## 7. 集成学习

### AdaBoost（自适应提升）

串行训练弱分类器，按错误调整样本权重，加权投票。

优点：自动特征选择、不易过拟合、二分类表现好。
缺点：对异常值敏感、训练慢、需选基分类器。

WebShell 检测：准确率 91.66%。

## 8. 聚类算法

### K-Means

无监督，将数据分 K 簇，最小化簇内距离。

优点：简单高效、适合球形分布。
缺点：需预指定 K、对初始值敏感、不适合非球形。

WebShell 检测：用于异常检测/数据预处理。

## 9. 神经网络

```text
MLP       全连接神经网络，拟合复杂非线性，需大量数据
CNN       卷积层提取特征 + 池化降维，适合图像/序列
RNN/LSTM  处理序列数据，捕捉长期依赖
BiLSTM    双向，上下文理解更强，计算量翻倍
Attention 动态关注重要信息，可解释性强
```

## 11. 算法选择建议

```text
需要快速响应    → 逻辑回归
需要高准确率    → LightGBM
需要可解释性    → 逻辑回归 / 决策树
数据量大        → LightGBM / 逻辑回归
特征维度高      → SVM / 随机森林
数据不平衡      → 随机森林 / LightGBM
小数据集(<1万)  → 逻辑回归、SVM、朴素贝叶斯
中数据集(1-10万) → 随机森林、LightGBM
大数据集(>10万)  → LightGBM、逻辑回归
```

多级检测架构：

```text
第一层：逻辑回归（快速过滤 ~95%）
  ↓
第二层：LightGBM（精细检测 97%）
  ↓
第三层：人工审核（可疑样本）
```

---

> **一句话总结**：树模型/集成（RF/LightGBM）是分类任务的主力，逻辑回归用于快速可解释场景，SVM 适合高维小样本。实践上按"准确率需求 × 速度 × 可解释性"选型。
